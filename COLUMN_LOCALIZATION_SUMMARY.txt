Layer 2: Schema Files (schemas/csv/*.columns.json)
  Stores metadata with Chinese labels

Layer 3: Rendering (src/app/components/tables/CsvGridHeader.vue)
  Displays: column.schema?.label ?? column.key

=====================================================
WHEN ADDING NEW COLUMNS
=====================================================

To add a new column to ships table:

1. Update TABLE_COLUMNS in src/shared/lib/starsector.ts:
   ships: ['name', 'id', ..., 'new_column']

2. Add schema entry in schemas/csv/ships.columns.json:
   { "key": "new_column", "label": "新列", "control": "text" }

That's all! The system will then display the Chinese label.
