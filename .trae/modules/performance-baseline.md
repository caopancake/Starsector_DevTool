# 性能计时与基线样本

## 定义

性能计时与基线样本用于记录加载、派生数据和高频交互的耗时，结果写入应用 log，作为后续性能预算和优化判断依据。

## 边界

- 后端 session 打开、目录识别、游戏概览和按需 query 计时归属项目加载系统。
- 前端打开 session、切表、CSV Grid 建模和单元格交互计时归属对应前端流程。
- CSV 读取计时必须细分到单表、字节读取、`alex_csv` 解析、行列规范化、结果组装和表格装饰。
- manifest 计时必须覆盖后端生成体积探针、前端 invoke 接收耗时和前端体积探针。
- 性能计时只记录阶段名、耗时、数量和路径类上下文，不记录大字段内容。

## 规范

- 性能 log 使用现有 app log，不新增日志文件。
- 性能 log 使用 `PERF` 前缀，级别为 `info`。
- 性能计时不得改变读取、保存、缓存、文件 history、编辑模式或诊断语义。
- 体积探针只能记录字节数、模块数量和 warning 数，不记录项目数据内容。
- 性能样本路径只用于人工验收，不得写入代码、测试或默认配置。
