# 表格保存与变更集

## 定义

将当前 CSV dirty patches 与用户确认的关联 spec 动作组成一次原子文件 changeset。

## Owner 与链路

- table-save orchestrator 捕获当前 mod/table/draft/候选动作并确认；Rust write service 校验 session/root、合成 CSV 和关联目标、构建/应用 changeset、返回 rowKey map/invalidation。
- 成功后 File History Session 记录、refresh，tables 才应用映射并提交 base/清 history。

## 不变量

- 关联动作仅为该表正式声明的目标；重命名经 JSON-like parser，不用字符串替换。
- 无实际 changes 不记 history/不清草稿；任一失败不提交本地保存状态或生成空文件。
