# 性能基线

## 定义

以正式计时日志和可复现样本记录关键链路性能，不改变业务行为。

## Owner 与链路

- 观测入口、样本格式和日志归专用性能模块；业务调用点仅提供正式阶段数据。
- 基线用于比较同一场景的端到端阶段，不是功能 fallback 或优化授权。
- Mod 打开记录 `project.openSession` 的后端阶段和前端 invoke；新建 Mod 分别记录磁盘创建 `frontend.createModProject` 与受信结果打开 `frontend.openCreatedModProject`；`persistent_index` 阶段明确记录 `hit` / `miss`，配置引用分别记录目录查询、按 ID 预览引用与资源 batch，避免把缓存热身误判为首开性能。
- 生产构建的入口依赖也是启动基线：窗口根必须独立按需加载，Naive 仅注册当前模板实际使用的控件，非 provider 控件按首次渲染加载。该链路将主入口产物从约 1.74 MB 降至约 0.35 MB，主窗口根另为约 0.08 MB。

## 不变量

- 不引入临时计时 API、调试分支、样例专用优化或影响保存/query 语义的观测。
- 记录输入规模、环境、阶段与结果；性能结论须由样本而非直觉得出。
