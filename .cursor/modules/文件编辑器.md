# 文件编辑器

## 定义

独立窗口编辑一个已授权 Mod 文本文件，并接入保存和文件级回放同步。

## Owner 与链路

- window identity 为 `sessionId + modRoot + path`；ViewModel 拥有文本 Draft Session、加载、保存请求、行聚焦和外部文本暂存。
- 保存经 file-save orchestrator -> service/API -> Rust 校验/changeset；主窗口记录 history、refresh 后向命中窗口发送文本事件。

## 不变量

- Rust 必须校验 `modRoot` 归属，前端不拼路径/直写。保存只写当前文件。
- dirty 窗口接收回放文本只能暂存，不能覆盖 textarea；窗口复用通过明确聚焦上下文事件。
