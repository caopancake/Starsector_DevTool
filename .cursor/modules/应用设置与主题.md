# 应用设置与主题

## 定义

管理 settings 运行态、app-data 持久化、主题/editMode 与子窗口完整镜像。

## Owner 与链路

- Rust `app_settings` service 是 `settings.json` 的 UTF-8 strict JSON owner；`settings.store` 是运行态、枚举/范围校验、token/snapshot owner。
- 主窗口 `load -> initialize store -> persistence watcher -> save command -> normalized snapshot -> broadcast`；子窗口只能从 URL snapshot 初始化并监听完整 snapshot 事件。
- `historyLimit` 由 persistence 同步到两种 history store；`SettingsPage` 仅写 store，不直接 IPC。

## 不变量

- settings 只写 app data，禁止 browser storage/workspace/Mod；子窗口不读写文件、不补默认值。
- `theme/accent/editMode` 使用正式枚举；字段入口消费 editMode。主题只由 store、root token 和 provider 驱动。
- `starsectorRoot` 仅默认目录提示；`logDirectory=null` 表示 app data。Rust 必须先校验/创建自定义日志目录（拒绝 app data、Mod、workspace、链接及不可写路径），成功后才保存并回传完整规范化 snapshot；日志名固定。
