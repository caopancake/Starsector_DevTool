# 目录打开

## 定义

将用户选定目录识别为游戏概览或 Mod，并建立正式 ProjectSession。

## Owner 与链路

- 组件请求目录；directory-opening orchestrator 调用后端识别，分派 game overview 或 `open ProjectSession`，再写 workspace/project 状态与反馈；新建 Mod 成功后也复用此入口加载创建结果。
- Rust root service 拥有 canonical 路径、目录类型、游戏/Mod 识别与 session 打开；workspace 只消费 outcome。

## 不变量

- 游戏概览不等于已加载 Mod；只有成功 session 才可驱动业务 query。
- 失败仅回滚本次注册的运行态，不覆盖已有 workspace；路径判断与安全校验只以后端为准。
- 游戏目录的 `mods` 目标由本模块以同一游戏根判定和路径边界解析；新建 Mod 不自行推导或拼接未校验的游戏路径。
