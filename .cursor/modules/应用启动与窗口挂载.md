# 应用启动与窗口挂载

## 定义

按 URL 窗口类型初始化依赖与 settings，再挂载对应 Vue 根。

## Owner 与链路

- `main.ts` 解析窗口参数，主窗口加载 settings；子窗口解析主窗口传入 settings snapshot；随后创建 Vue、Pinia、Naive provider 与窗口根。
- 主窗口挂载应用壳；编辑器与文件编辑器仅挂载各自根组件/目标 ViewModel。
- 主窗口壳只同步加载标题栏与导航；工作区页面按当前视图异步挂载，配置子页按当前配置路由异步挂载。

## 不变量

- URL 是窗口身份输入，不是未校验业务数据；缺失/非法必需参数显示启动错误且不挂载业务 UI。
- settings 读取/保存只在主窗口；子窗口不自行读盘或补默认。窗口创建、单例和事件不归此模块。
