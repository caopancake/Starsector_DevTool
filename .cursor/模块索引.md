# 模块索引（AI 路由）

模块文档是长期 ownership/链路事实；设计候选写 `参考设计.md`，阶段任务写 `待办事项.md`。改动一个模块前先读对应文档与当前实现；行为边界变化才更新文档。

## 模块文档格式

- 使用三段短契约：`定义`（模块范围）、`Owner 与链路`（真实 owner 和调用顺序）、`不变量`（输入/输出/状态/保存/错误边界）。不记录任务、候选方案或临时过程。
- 正文只写可约束代码的事实，不用泛指、凑行数或穷尽式许可清单；链路按调用顺序，禁止边界写为不可发生的越权行为。
- 任何模块不得绕过正式 IPC、磁盘读写或 parser/mapper/normalizer；状态、持久化、路由、反馈、日志与外部资源必须归明确 owner。

## 按问题选择文档

| 主题                             | 模块文档                                                                                               |
| -------------------------------- | ------------------------------------------------------------------------------------------------------ |
| 启动/多窗口/设置/反馈            | `应用启动与窗口挂载`、`多窗口机制`、`应用设置与主题`、`应用反馈与日志`                                 |
| 目录、新建 Mod、工作区、项目会话 | `目录打开`、`新建Mod`、`工作区`、`项目会话`                                                            |
| 表格、草稿、保存、历史           | `表格解析器`、`表格编辑`、`草稿会话`、`表格草稿历史`、`表格保存与变更集`、`文件历史`、`主窗口历史命令` |
| 文件、配置文本、变更集           | `文件编辑器`、`配置文本解析器`、`后端文件读写与变更集`                                                 |
| 配置与字段模式                   | `配置系统`、`字段模式系统`、`舰船皮肤编辑器`、`装配编辑器`                                             |
| 专用编辑器/预览                  | `舰船编辑器`、`武器编辑器`、`弹体编辑器`、`战术系统编辑器`、`武器发射预览`                             |
| 资源、性能、关于页               | `资源与原版回退`、`性能基线`、`关于页面`                                                               |

新增模块：先在此表建立路由，再落盘完整模块契约；不因文件大而拆分。
