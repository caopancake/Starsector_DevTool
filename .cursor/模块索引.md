# 模块索引（AI 路由）

模块文档是长期 ownership/链路事实；设计候选写 `reference.md`，阶段任务写 `todo.md`。改动一个模块前先读对应文档和其 `参考` 列出的实现；行为边界变化才更新文档。

## 模块文档格式

- 保留：`定义`（一句）、`参考`（关键 owner）、`边界`（谁拥有/谁只能消费）、`链路`（真实顺序）、`规范`（输入/输出/状态/错误/保存）、`陷阱`（反向错误）。章节不重复；不记录任务、候选方案或临时过程。
- `链路` 按调用顺序；其它同级约束按字典序。正文写可约束代码的事实，不用泛指、凑行数或穷尽式许可清单。
- 模块内不得直接 IPC、磁盘读写或绕过 parser/mapper/normalizer；状态、持久化、路由、反馈、日志与外部资源必须归明确 owner。

## 按问题选择文档

| 主题                     | 模块文档                                                                                                                        |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------- |
| 启动/多窗口/设置/反馈    | `app-window-mounting`、`windowing`、`app-settings`、`app-feedback-log`                                                          |
| 目录、workspace、session | `directory-opening`、`workspace`、`project-session`                                                                             |
| CSV、草稿、保存、历史    | `csv-parser`、`csv-tables`、`draft-session`、`csv-edit-history`、`table-save-changeset`、`file-history`、`main-history-command` |
| 文件、JSON、路径与变更集 | `file-editor`、`json-parser`、`rust-file-io-changeset`                                                                          |
| 配置与 schema            | `config`、`schema`、`skin-editor`、`variant-editor`                                                                             |
| 专用编辑器/预览          | `ship-editor`、`weapon-editor`、`projectile-editor`、`system-editor`、`weapon-preview`                                          |
| 资源、性能、关于页       | `assets-core-fallback`、`performance-baseline`、`about-page`                                                                    |

新增模块：先在此表建立路由，再落盘完整模块契约；不因文件大而拆分。
