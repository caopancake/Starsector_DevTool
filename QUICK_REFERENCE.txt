================================================================================
HOW IT WORKS
================================================================================

Data flow:
1. Schema JSON files contain: { "key": "name", "label": "名称" }
2. csvColumnSchemaFor() retrieves schema including label
3. createCsvGridColumn() stores schema in CsvGridColumn object
4. CsvGridHeader.vue receives columns with schema included
5. Template displays: column.schema?.label (shows "名称")
6. Fallback: ?? column.key (shows "name" if label missing)

Safety:
- Uses nullish coalescing operator (??)
- If label exists, use it
- Otherwise, fall back to key
- Always displays something meaningful
