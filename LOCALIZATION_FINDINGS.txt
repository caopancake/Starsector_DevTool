  TABLE_COLUMNS -> getColumns() -> CsvGridColumn -> CsvGridHeader.vue -> Display

================================================================================
IF YOU SEE ENGLISH HEADERS
================================================================================

This should NOT happen (localization is complete), but if it does:

Possible causes:
  1. Column not in TABLE_COLUMNS (might be dynamic from CSV)
  2. Schema file wasnt reloaded (clear cache and rebuild)
  3. Browser cache issue (Ctrl+Shift+Del to clear)

Fix steps:
  1. Verify column is in TABLE_COLUMNS
  2. Verify schema entry exists with matching key
  3. Verify schema entry has "label" field
  4. Rebuild frontend: npm run build
  5. Clear browser cache
  6. Reload page

================================================================================
WHEN ADDING NEW COLUMNS
================================================================================

To add "new_column" to the ships table:

Step 1: Update TABLE_COLUMNS in src/shared/lib/starsector.ts
  ships: [
    ...,
    "new_column"
  ]

Step 2: Add schema entry in schemas/csv/ships.columns.json
  {
    "key": "new_column",
    "label": "新列",
    "control": "text"
  }

Step 3: Rebuild and test
  npm run build
  Test in browser
